## Routing

Choose an action from `$ARGUMENTS`, the text entered after `/cc-session`.

| `$ARGUMENTS` | Action |
|---|---|
| Empty | Run `cc-session list`, show the sessions, and ask which one to inspect |
| `list` with optional `-p` or `-n` | Run `cc-session $ARGUMENTS` and show the list |
| A bare session ID such as `16d06326` | Treat it as a request to read that session and use the inherit pagination flow |
| Known subcommand with arguments: `inherit`, `read`, `context`, `expand`, `stats`, `audit`, `usage` | Run `cc-session $ARGUMENTS`; paginate when the command is `inherit` |

The `argument-hint` frontmatter is generated by `cc-session help --argument-hint` and synchronized during installation. Do not edit it manually.

## Reading session content

`read` truncates at 200 lines by default, so it usually shows only the beginning of a long session. `inherit` loads the complete session in pages of no more than 28K characters.

Use `inherit` for complete session reading. Use `read -offset` only when the user explicitly asks for a specific section.

### Inherit flow

`inherit` remembers its progress. Repeating the same command advances automatically:

1. `cc-session inherit <id>` returns page 1 with `[page 1/N | lines X-Y of Z]`.
2. Run the same command again to receive page 2.
3. Continue until the output includes `[inherit complete]`.
4. Analyze the session only after all pages have been loaded.

Use `-page N` to jump to a page and `-reset` to clear progress.

## Dialogue-Preserving Resume Protocol (Cache Expiration Recovery)

When a session exceeds 1 hour (Prompt Cache expiration) or is resumed across days, built-in `/compact` often discards essential file paths, unresolved action items, and specific error traces through over-summarization. Use `cc-session` for lossless dialogue reconstruction:

1. **Locate target session**:
   Run `cc-session list -n 5` to identify the interrupted session ID.
2. **Evaluate volume and compression ratio**:
   Run `cc-session stats <id>` to inspect character counts and noise reduction (benchmarked at 85.1% noise reduction on 495k+ char sessions while preserving all conversational fidelity and tool summaries).
3. **Losslessly inherit into a fresh session**:
   In the newly started agent session, run:
   `cc-session inherit <id> -reset`
   Follow the paged prompts until `[inherit complete]`, restoring 100% human-agent reasoning context without hallucination or context drift.

## Output behavior

- Message headers use `[HH:MM:SS]`; a separate `--- YYYY-MM-DD ---` line marks date changes.
- `user:` is typed human input; `assistant:` is Claude; `harness:` is content injected by Claude Code, such as stop-hook goals, background task notifications, compaction continuation, and interruption markers; `user (sdk):` is sent programmatically through the SDK or `claude -p` and occupies the user position without being manually typed.
- Tool summaries mark only failures with `FAILED`; successful calls are unmarked. Bash lines include `| <program subcommand>` to show what actually ran.
- Consecutive calls that inherit, read, or load the same session are collapsed to one line such as `(cc-session#Y1dg: inherited session 16d06326 here, 1320 lines omitted)`.
- Historical `cc-session inject` calls, from before the rename, are collapsed with the original `injected session X here` wording.
- Tool IDs such as `#Y1dg` remain available for `cc-session expand`.
- `-verbose-bash` disables Bash-output compression and displays complete output.
